# 氧分析仪实时监控系统 v4.0 - 使用说明

## 系统概述

氧分析仪实时监控系统 v4.0 是一个集成了故障诊断与维修建议的 MATLAB 监控系统。该系统不仅能够实时监测氧浓度数据并诊断故障，还能根据故障类型自动提供详细的维修建议。

### 主要特点

✅ **实时异常检测**：满量程、零位、数据缺失、数据保持  
✅ **定期综合诊断**：剧烈波动、数据偏移（6种细分类型）  
✅ **智能维修建议**：基于故障代码自动匹配维修措施  
✅ **完整维修数据库**：包含23种故障类型的详细维修步骤  
✅ **实时可视化**：动态图表显示监控数据和异常点  
✅ **报告自动生成**：生成包含维修建议的完整报告

## 快速开始

### 1. 环境要求

- **MATLAB 版本**：R2018b 或更高版本
- **必需工具箱**：Statistics and Machine Learning Toolbox
- **数据文件**：Excel 格式 (.xlsx)

### 2. 数据文件准备

准备一个 Excel 文件，命名为 `7_twohour.xlsx`（或在代码中修改文件名），格式如下：

**选项1：单列数据（仅氧浓度）**
```
氧浓度
5.12
5.15
5.18
...
```

**选项2：双列数据（时间戳 + 氧浓度）**
```
时间戳           氧浓度
2025-10-08 00:00  5.12
2025-10-08 00:01  5.15
2025-10-08 00:02  5.18
...
```

### 3. 运行程序

1. 将数据文件放在 MATLAB 工作目录中
2. 打开 `oxygen_analyzer_monitor_enhanced_with_maintenance.m`
3. 运行脚本（按 F5 或点击"运行"按钮）

### 4. 配置参数（可选）

在代码开头的"系统配置部分"可以修改以下参数：

```matlab
config.data_file = '7_twohour.xlsx';        % 数据文件名
config.start_time = datetime(2025,10,8,0,0,0); % 起始时间
config.sample_interval = 1;                 % 采样间隔(秒)
config.diagnosis_interval = 3600;          % 诊断间隔(秒)
config.simulation_speed = 100;              % 模拟速度
config.enable_visualization = true;         % 是否启用可视化
config.save_log = true;                     % 是否保存日志
```

| **003** | 数据缺失 | 检测到NaN值 | 每10分钟 |

## 维修建议系统

### 维修数据库分类

系统维修建议数据库包含以下4大类、23种故障类型：

#### 1. 数据偏差型故障（7种）
- 302: 零点漂移超过允许范围50%
- 303: 零点漂移超出允许范围
- 304: 灵敏度漂移超出50%
- 305: 灵敏度漂移超出允许范围
- 319: 磁力测量回路失衡
- 320: 测定放大偏差过高
- 309-311: 温度调节器失效

#### 2. 数据传输中断型故障（8种）
- 101: 系统控制器关停
- 116: Profibus安装错误
- 201-209: 系统总线连接中断
- 300: 模数转换器无输出
- 308: 测定值计算错误
- 318: ADC无新测量
- 332-337: I/O板故障
- 338-339: 模拟线路故障

#### 3. 数据保持型故障（3种）
- 301: 超出ADC阈值
- 344: 超上限130%
- 345: 低于下限-100%

#### 4. 数据波动型故障（3种）
- 312: 压力修正失效
- EXT-01: 管路污染堵塞
- EXT-02: 气路扭结泄漏

### 维修建议输出格式

每个故障诊断后，系统会输出：

```
【故障代码】时间 - 故障描述
【维修建议】
  ┌─ 可能原因1: 故障名称 (故障代码:xxx)
  │  故障类型: xxx
  │  严重程度: xxx
  │  维修优先级: Px
  │
  │  维修步骤:
  │    1. 检查项目1
  │       预计时间: xx分钟 | 所需工具: xxx
  │    2. 检查项目2
  │       预计时间: xx分钟 | 所需工具: xxx
  │    ...
  ┌─ 可能原因2: ...
  └─────────────────────────────────────

  ⚠ 建议：请按优先级从高到低依次检查上述可能原因
```

## 输出文件说明

运行完成后，系统会生成以下文件：

### 1. 监控报告 (TXT格式)
**文件名**: `O2_Monitor_Enhanced_Report_YYYYMMDD_HHMMSS.txt`

包含内容：
- 监控统计总结
- 故障统计详情
- 实时报警记录（含维修建议）
- 定期诊断记录（含维修建议）

### 2. 报警数据 (Excel格式)
**文件名**: `O2_Alarms_Enhanced_YYYYMMDD_HHMMSS.xlsx`

包含内容：
- 报警时间戳
- 对应的氧浓度值

### 3. 监控图表 (PNG格式)
**文件名**: `O2_Monitor_Enhanced_Final_YYYYMMDD_HHMMSS.png`

包含内容：
- 实时氧浓度监控曲线
- 1小时数据窗口
- 实时统计信息
- 诊断日志

## 常见问题 (FAQ)

### Q1: 如何调整诊断阈值？

在代码的"诊断阈值配置"部分修改：

```matlab
thresholds.full_scale = 9.95;      % 满量程阈值
thresholds.zero_scale = 0.05;      % 零位阈值
thresholds.normal_mean = 5.0;      % 正常均值
thresholds.small_offset = 0.5;     % 小幅偏移阈值
thresholds.large_offset = 1.5;     % 大幅偏移阈值
thresholds.high_std = 0.5;         % 剧烈波动阈值
```

### Q2: 为什么同一故障不会连续报警？

系统采用周期性报警控制机制。对于实时监测类故障（001-004），默认每10分钟报警一次，避免报警信息过于密集。

如需调整报警间隔：
```matlab
periodic_alarm_control.alarm_interval = 600; % 10分钟 = 600秒
```

### Q3: 如何添加自定义维修建议？

在 `initialize_maintenance_database()` 函数中添加新的故障记录：

```matlab
db{end+1} = struct(...
    'fault_type', '故障类型', ...
    'fault_code', '故障代码', ...
    'fault_name', '故障名称', ...
    'description', '故障描述', ...
    'severity', '严重程度', ...
    'priority', 优先级数字, ...
    'maintenance_measures', {{
        struct('step', 1, 'action', '维修步骤1', 'time', '时间', 'tools', '工具');
        struct('step', 2, 'action', '维修步骤2', 'time', '时间', 'tools', '工具');
        ...
    }});
```

然后在 `get_maintenance_advice()` 函数中添加映射关系。

### Q4: 可以实时监控多个设备吗？

当前版本设计为单设备监控。如需监控多设备，建议：
1. 为每个设备运行独立的 MATLAB 实例
2. 修改代码支持多线程（需要 Parallel Computing Toolbox）
3. 开发分布式监控系统

### Q5: 如何导出历史数据分析报告？

系统自动保存3种报告文件：
1. TXT报告：包含完整的文字记录
2. Excel报告：包含报警时间和数值
3. PNG图表：包含可视化曲线

可以使用这些文件进行二次分析。

   - 关闭可视化（`config.enable_visualization = false`）
