# 氧分析仪监控系统 - 维护建议集成版

## 概述

本系统在原有氧分析仪实时监控系统的基础上，集成了完整的维护建议数据库，能够根据检测到的故障自动提供相应的维护措施建议。

## 新增功能

### 1. 维护建议数据库 (MaintenanceDatabase.m)
- **完整的故障代码库**：包含所有故障类型及其对应的维护措施
- **多级维护措施**：每个故障提供5个级别的维护建议
- **详细维护信息**：包括维护措施描述、预计时间、所需工具等
- **灵活查询接口**：支持按故障代码、故障类型等多种方式查询

### 2. 增强的监控系统 (O2_Monitor_Enhanced_with_Maintenance.m)
- **实时维护建议**：检测到故障时立即显示维护建议
- **维护建议统计**：统计各类故障的维护建议数量
- **可视化维护面板**：在监控界面显示最近的维护建议
- **详细维护报告**：生成包含维护建议的详细报告

## 使用方法

### 1. 基本使用
```matlab
% 运行集成维护建议的监控系统
O2_Monitor_Enhanced_with_Maintenance
```

### 2. 单独使用维护数据库
```matlab
% 创建维护数据库实例
maintenanceDB = MaintenanceDatabase();

% 根据故障代码查询
fault_info = maintenanceDB.getFaultByCode('001');

% 显示维护建议
maintenanceDB.displayFaultInfo(fault_info, fault_info.maintenance_measures);
```

### 3. 测试系统
```matlab
% 运行测试脚本
test_maintenance_system
```

## 维护建议结构

每个维护建议包含以下信息：
- **级别**: 1-5级维护措施
- **措施描述**: 具体的维护操作
- **预计时间**: 完成维护所需时间
- **所需工具**: 维护过程中需要的工具

## 输出文件

系统运行后会生成以下文件：
- `O2_Monitor_Enhanced_Maintenance_Report_YYYYMMDD_HHMMSS.txt`: 详细监控报告
- `O2_Alarms_Enhanced_Maintenance_YYYYMMDD_HHMMSS.xlsx`: 报警数据Excel文件
- `O2_Maintenance_Recommendations_YYYYMMDD_HHMMSS.xlsx`: 维护建议Excel文件
- `O2_Monitor_Enhanced_Maintenance_Final_YYYYMMDD_HHMMSS.png`: 监控图表

## 配置选项

在 `O2_Monitor_Enhanced_with_Maintenance.m` 中可以配置以下选项：

```matlab
config.enable_maintenance = true;           % 是否启用维护建议
config.data_file = '7_twohour.xlsx';        % 数据文件名
config.simulation_speed = 100;              % 模拟速度
config.enable_visualization = true;         % 是否启用可视化
config.save_log = true;                     % 是否保存日志
```

## 技术特点

1. **模块化设计**: 维护数据库独立封装，易于维护和扩展
2. **实时集成**: 故障检测与维护建议实时关联
3. **多级维护**: 提供从简单检查到设备更换的完整维护方案
4. **详细记录**: 完整的维护建议记录和统计
5. **灵活配置**: 支持启用/禁用维护建议功能

## 扩展说明

### 添加新的故障类型
1. 在 `MaintenanceDatabase.m` 的 `initializeFaultDatabase` 方法中添加新的故障记录
2. 在主监控系统中添加对应的故障检测逻辑
3. 更新故障代码映射关系

### 修改维护建议
1. 在 `MaintenanceDatabase.m` 中修改对应故障的 `maintenance_measures`
2. 使用 `createMeasure` 方法创建新的维护措施
3. 重新运行系统即可生效

## 注意事项

1. 确保数据文件 `7_twohour.xlsx` 存在于工作目录中
2. 维护建议基于通用故障模式，实际应用时请根据具体设备调整
3. 建议定期更新维护数据库以反映最新的维护经验
4. 系统生成的维护建议仅供参考，实际维护操作请遵循设备制造商指导
