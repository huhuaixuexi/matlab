# 故障诊断维修记录生成器

本项目用于生成模拟的故障诊断维修记录数据，并导出为Excel格式。

## 功能特点

1. **完整的故障数据库**
   - 包含4大类故障类型：数据偏差型、数据传输中断型、数据保持型、数据波动型
   - 22种不同的故障代码，每种都有详细的描述和维修措施
   - 每个故障包含5种不同的维修方案

2. **智能数据生成**
   - 5年时间范围内的随机分布
   - 根据故障代码自动匹配维修措施
   - 包含完整的维修信息（操作、耗时、工具）

3. **专业的Excel输出**
   - 格式化的表格样式
   - 根据严重程度的颜色标记
   - 自动列宽调整
   - 首行冻结和筛选功能

## 使用方法

1. 确保安装了必要的依赖：
   ```bash
   pip install pandas openpyxl numpy
   ```

2. 运行程序：
   ```bash
   python3 generate_fault_records.py
   ```

3. 程序会自动生成包含以下字段的Excel文件：
   - 故障时间
   - 仪表故障代码
   - 故障描述/名称
   - 故障类型
   - 严重程度
   - 优先级
   - 维修操作
   - 耗时
   - 工具

## 输出说明

- 生成的记录数量：900-1500条（平均每月15-25条）
- 时间范围：最近5年
- 文件格式：Excel (.xlsx)
- 文件命名：故障诊断维修记录_YYYYMMDD_HHMMSS.xlsx

## 统计信息

程序运行后会显示：
- 总记录数
- 故障类型分布
- 严重程度分布
- 故障代码分布（前10）
- 平均每月故障数

## 故障严重程度

- **紧急**：红色底色，白色字体（需立即处理）
- **严重**：橙色底色（需尽快处理）
- **中等**：黄色底色（计划性维修）
