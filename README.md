# 氧分析仪故障诊断与维护建议知识库系统 v2.0

## 概述

这是一个基于MATLAB的氧分析仪故障诊断与维护建议知识库系统，用于建立故障数据库并提供智能维护决策支持。

## 主要改进 (v2.0)

### 1. 修复的问题
- **字符串匹配问题**: 将 `contains` 改为 `strcmp` 进行精确匹配，避免误匹配
- **字段名安全性**: 使用 `regexprep` 生成安全的字段名，避免非法字符
- **输入验证**: 为所有公共方法添加了完整的输入验证和错误处理
- **性能优化**: 使用 `containers.Map` 优化统计报告生成性能

### 2. 新增功能
- **直接故障代码查询**: `getFaultByCode()` 方法
- **故障搜索**: `searchFaults()` 方法支持关键词搜索
- **故障列表**: `listAllFaults()` 方法列出所有故障
- **数据备份**: `backupData()` 和 `loadData()` 方法
- **增强的统计报告**: 包含最频繁故障TOP5等更多信息

### 3. 代码质量改进
- 添加了完整的错误处理机制
- 改进了代码注释和文档
- 优化了内存使用和性能
- 增强了代码的健壮性

## 使用方法

### 基本使用

```matlab
% 初始化知识库
kb = FaultKnowledgeBase();

% 查询故障信息
[fault_info, measures] = kb.getFaultInfo('数据偏差型故障', '302');
kb.displayFaultInfo(fault_info, measures);

% 记录维护日志
kb.logMaintenance('302', '清洁传感器表面', '成功', now);

% 生成统计报告
report = kb.generateStatisticsReport();
```

### 高级功能

```matlab
% 搜索故障
kb.searchFaults('传感器');

% 列出所有故障
kb.listAllFaults();

% 备份数据
kb.backupData('backup.mat');

% 导出Excel报告
kb.exportToExcel('report.xlsx');
```

## 故障类型

系统包含以下四类故障：

1. **数据偏差型故障** (302, 303, 304, 305, 319, 320, 309-311)
2. **数据传输中断型故障** (101, 116, 201-209, 300, 308, 318, 332-337, 338-339)
3. **数据保持型故障** (301, 344, 345)
4. **数据波动型故障** (312, EXT-01, EXT-02)

## 维护措施分级

每个故障都包含5级维护措施，从简单到复杂：

1. **Level 1**: 基础检查 (5-10分钟)
2. **Level 2**: 简单维护 (15-30分钟)
3. **Level 3**: 中等维护 (30-60分钟)
4. **Level 4**: 复杂维护 (1-2小时)
5. **Level 5**: 更换部件 (2-3小时)

2. 维护日志会自动保存到内存中
3. 建议定期备份数据
4. 统计报告基于历史维护记录生成
